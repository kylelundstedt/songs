About

KGL Songs

A private, performance-focused library for building, organizing, and using compact vocalist lead sheets.

Built for the stage

Lead sheets are automatically fitted into two readable columns on iPad, with a one-column phone layout and light or dark modes for different performance conditions.

Fast song creation

Add a Song searches permitted lyrics providers, lets you choose the recording, and uses a fast Shelley model to produce a best-effort draft with sections, compact repeated choruses, and preserved lyric lines.

Git-backed and reviewable

Markdown files in Git are canonical. SQLite is only a rebuildable search index. Imported lyrics retain source and original-recording metadata, while performance key and BPM remain separate.

Edit directly or with Shelley

Open the canonical Markdown in a full editor for hands-on changes, or ask for a focused correction without leaving the live sheet—for example, “Verse 3 is actually 14 bars.” Either path validates, commits, and refreshes the library.

Responsible use

This private library records source provenance and uses supported provider APIs. Add and use lyrics only when permitted by the source’s terms and applicable rights; responsibility remains with the library owner.
